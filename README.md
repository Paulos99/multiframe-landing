# StP MultiFrame — лендинг

Статичная страница по макету из Figma (PDF): HTML, CSS и немного JS, без сборки.

- `site/` — сама страница (публикуется на GitHub Pages через `.github/workflows/pages.yml`).
- `shots/` — снимки страницы: компьютер 1440 px и телефон 390 px.
- `shoot.py` — снимает эти скриншоты через Playwright: `python3 shoot.py <адрес>`.

Шрифт: файлов Geometria не нашлось, стоит близкий по рисунку Jost (локально, OFL). Если появятся файлы Geometria, положите их в `site/assets/fonts/` и замените `@font-face` в `style.css`.

Заглушки, которые нужно заменить: телефон 8 800 123-45-67, ссылки «Подробнее», «Где купить», «О компании», «Для дилеров», «Блог», карточки проектов.
